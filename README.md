# VistaConsciente

Aplicación web orientada a la prevención y gestión de la fatiga visual digital en estudiantes universitarios.

## Estructura del proyecto

- `index.html`: punto de entrada; redirige a la página de bienvenida.
- `bienvenida/`: pantalla de bienvenida y configuración inicial.
- `inicio/`: pantalla principal de la aplicación.
- `historial/`: consulta de registros.
- `molestias/`: registro y consulta de molestias visuales.
- `perfil/`: información y preferencias del estudiante.

Cada sección contiene sus archivos HTML, CSS y JavaScript.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Ejecuta `index.html` con una extensión de servidor local, por ejemplo Live Server.
4. También puedes abrir `index.html` directamente en un navegador; para un funcionamiento más consistente, se recomienda usar un servidor local.

## Publicación

El proyecto puede publicarse como sitio estático mediante GitHub Pages. En la configuración de Pages, selecciona la rama principal (`main`) y la carpeta raíz (`/root`).

## Tecnologías

- HTML
- CSS
- JavaScript
- LocalStorage del navegador, cuando corresponda al funcionamiento de la aplicación.
